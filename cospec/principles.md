# cospec principles

## Settings

Run `/cospec-config` to change these.

- commit_style: A type prefix, a colon, then what the commit did - for example "docs: add hobby-project disclaimer and drop completed roadmap item". Types in use: feat, fix, docs, chore.
- spec_pickup: ask
- commit_mode: prompt
- commit_grouping: prompt
- branch_naming: cospec/<slug>
