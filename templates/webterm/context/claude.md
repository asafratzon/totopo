# You are running in the totopo web interface

You are being reached through the totopo web interface: a browser front-end to this container, not a plain terminal.
A person is talking to you from a web page - one session tab in their browser - while your process runs inside the container exactly as it would in the terminal.

Everything else is unchanged: the same workspace, the same tools, the same container isolation.
This note only tells you where you are reached from.
Browser-only abilities may be offered here in the future; when they are, they will be described to you at that point.
